## Talk Summary

Presented at SCTE TechExpo 2026 (Sep 29–Oct 1, Atlanta, GA). Builds on the autonomic, closed-loop (MAPE) control work from my dissertation on programmable DOCSIS access networks, extending the argument up the stack: as cable operators adopt intent-based networking to automate configuration and policy, that automation has to be reconciled with the tightening latency guarantees of Low Latency DOCSIS and low-latency mobile backhaul. Discusses where intent-based control helps operationalize autonomy at scale, and where it needs to defer to the network's real-time constraints.
